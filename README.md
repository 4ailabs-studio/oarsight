# Oarsight

**AI supervision for motivational interviewing.**

Oarsight listens to a clinical consultation and gives the clinician verified feedback on how they used motivational interviewing: the key moments, what they could say instead, targeted voice practice with a simulated patient, and a briefing for the next visit with the same patient.

Built with Meta Model API (Muse Voice Transcribe, Muse Wonder, Muse Spark) for the Meta Global AI Developer Hackathon, October 26 – November 4, 2026.

> **Status:** in development during the hackathon.

## Data notice

This project uses **only fictional or role-played consultations**. No real patient data is stored in this repository or used in the demo. Oarsight is a training and decision-support tool for clinicians; it does not give medical advice.
